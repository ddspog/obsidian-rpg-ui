# GM Screen

A solo-play GM Screen. It **assigns** GM tools from `gm-tools/` (in the
`gm-tools:` frontmatter above) and surfaces them as cards on the GM side of any
session log that links this file via `gm: "[[00. GM Screen]]"`. Each assigned
tool's `rpg feature.gm` blocks become card stacks; open a tool's own page to
read how it works and play with its example.

## Assigned tools

- **Dial:** [[Chaos Factor]] (the session's tension dial — supplies the current `[CF:n]`, defaulting to 5, that every oracle tests against)
- **Scene:** [[First Scene]] (open the adventure), [[Scene Check]] (test the expected scene), [[Automatic Interrupt]] (force an interrupt when stuck)
- **Table:** [[Scene Adjustment]] (randomly alter a scene)
- **List:** [[Threads]] (open quests the PC is pursuing — supplies `[Threads?]` consults, defaulting to "Any Thread")
- **Event:** [[Random Event]] (a Random Event generator composing the Event Focus + Event Meaning sub-generators in parallel)

These are the tools defined by the "Scenes" chapter (plus the Chaos Factor dial
the oracles read). The remaining oracle, event, generator, npc, faction,
location, and clock tools (Fate Chart, Random Event, Meaning Tables, NPC, NPC
Behavior, …) return as their own source chapters are processed.

Add more by dropping a tool page into a `gm-tools/<type>/` folder and listing it
under `gm-tools:`.
