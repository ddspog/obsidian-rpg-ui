#### Table 24-4: Legendary Terrain Feature Names 4
Some terrain features are named for a resemblance to an item. For example, a mountain might be called “The Anvil” either because of a flat top or because it is used as an anvil by a deity in the local mythology. These don’t work across the board in all situations, so you may want to use this more as a list of options than as a random generation table — because when they do work, they can add quite a bit of variety to the naming of places.

**Sample Results**: The Alembic, the Anvil, the Bottle, the Goblet.

# Strongholds
![[strongholds.webp|right|384]]There are six main formulas for the name of a stronghold:
- **Formula 1**: \[[[24. Names for Legendary Places#Table 24-5 Type 1 Fortress Name 1|Table 24-5: Type 1 Fortress Name 1]]\] \[[[24. Names for Legendary Places#Table 24-6 Type 1 Fortress Name 2|Table 24-6: Type 1 Fortress Name 2]]\] (based on the first result, the order may be switched). This yields results such as Fortress Marzathor or Khekra Keep.
- **Formula 2**: The \[[[24. Names for Legendary Places#Table 24-6 Type 1 Fortress Name 2|Table 24-6: Type 1 Fortress Name 2]]\]. This yields results such as The Gharachaga or The Sarambor. Alternatively, you can also use [[29. Miscellaneous Tables#Table 29-2 General Items|Table 29-2: General Items]] for this sort of name, to get results like The Alembic or The Bracelet.
- **Formula 3**: (The Fortress of X): The Bastion of (personal name). For this formula, roll on [[24. Names for Legendary Places#Table 24-7 Type 2 Fortress Name|Table 24-7: Type 2 Fortress Name]]. This generates names such as The Bastion of Arnaud One-Eye. The need to generate a personal name makes this one take a bit longer than the others.
- **Formula 4**: “Fortress” of the [Group]. For this formula, use \[[[24. Names for Legendary Places#Table 24-7 Type 2 Fortress Name|Table 24-7: Fortress Name Type 2 (Column 1)]]\] \[[[24. Names for Legendary Places#Table 24-8 Type 3 Fortress Name Part 1|Table 24-8: Type 3 Fortress Name 1]]\] \[[[24. Names for Legendary Places#Table 24-9 Type 3 Fortress Name Part 2|Table 24-9: Type 3 Fortress Name 2]]\]. This generates names such as The Spires of the Ghost-Thieves.
- **Formula 5**: Castle \[[[24. Names for Legendary Places#Table 24-10 Short Castle Name|Table 24-10: Short Castle Name]]\]. This generates shorter castle names, such as Castle Mask or Castle Spring.
- **Formula 6**: The Fortress of \[[[24. Names for Legendary Places#Table 24-11 Mystical Fortress Name 1|Table 24-11]] or [[24. Names for Legendary Places#Table 24-12 Mystical Fortress Name 2|12]]: Mystical Fortress 1 or 2]. This yields names such as the Fortress of Ancestry, or the Fortress of Antidotes.

You can also go to the Tome of Worldbuilding, starting with [[09. Legendary Locations#Table 9-16 Stronghold Type|Table 9-16: Stronghold Type]] to generate stronghold names that are somewhat different from the tables in the Nomicon.
