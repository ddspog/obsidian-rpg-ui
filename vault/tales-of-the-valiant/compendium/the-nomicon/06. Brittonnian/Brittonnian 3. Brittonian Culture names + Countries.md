# Brittonian Culture names
![[brittonian-culture-names.webp]]

One way of naming a Brittonnian culture is to use [[Celtigaulic 2. Cultures + Tribes#Table 7-4 Celtigaulic Tribal Names|Table 7-4: Celtigaulic Tribal Names]]. Otherwise, use [[Brittonnian 3. Brittonian Culture names + Countries#Table 6-12 Brittonnian Country Names|Table 6-12: Brittonnian Country Names]]. To generate a tribal name, add “-i” to the end of the country name.

The following historically-accurate endings can be added for additional variation in these names.
- -doini “people,” Old Irish
- -dowinis, proto-Celtic
- Add -tuath (people or tribe, Irish)
- -tuath (a territorial unit, Old Irish)
- Add -tir (Welsh) for -land
- -lann (land) Old Irish
- Muintir na \_\_\_\_\_\_ The people of (as -ish)
- -cine (race) Irish
