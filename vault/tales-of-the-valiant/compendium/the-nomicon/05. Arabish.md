# Name Of Culture
This is for the name of a culture for which you’re going to use the Arabish Naming Group.

In (real-world) Arabic, the suffix “-i” denotes a people. So it’s like “ic” for Celtic (or “ish” for English). -een is a plural (in Arabic it’s usually for a masculine noun). So it’s like “s” in Celts.

The suffix “-stan,” which comes from Persian, is the equivalent of the suffix “-land,” literally meaning “where one stands,” or “place of the.” For clarity in a game world, I recommend using “-stan” for cities only.

**Instructions**: Roll 1d12 to see which table to use for generating the name of the culture.

These tables also work well for generating country and terrain names; just don’t add the -i or -een ending.

## More of a Persian style than Arabic-style

# Terrain feature names
Note: if you are looking for a broader range of terrain names than the method below, you can also roll for a culture name. The culture names all end with -i, a suffix which works like -ish in the English language. Remove that final -i from the culture name, and you have a workable base word for a terrain feature.
## The Terrain name table

This generates names such as “The Aafan Marshes.” There are some dialect options in the Suffix 2 Table.
- **Formula 4**: For a hyphenated name such as “The Marshes of Aafa-Bai,” “The Aafa-Bai,” or the “Marshes of the Aafa-Bai,” roll for the Terrain Name (alone) and then add a hyphenated suffix from [[05.
