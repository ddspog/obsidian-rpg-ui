# Street Names
## List of Street Types/names
When you’re naming streets, use as much variation as possible, or the map will look repetitious.
### The Full List:
Alley, Avenue, Boulevard, Circle, Close (a dead end or a narrow passage between buildings), Gate, Lane, Market, Mews (lane), Road, Square, Street, Trace, Walk, Way. Not all of these are used in the tables below because many of them are specific types of streets.
#### Table 25-5: Selected Street Types
A shorter list than above, but these all work with the tables below. Check with the list above every once in a while to see if you can use the “extra” ones for variation.

**Sample Results**: Alley, Avenue, Boulevard.

```rpg table.selected-street-types
|dice:d10|Street Type|
|---|---|
|1|Alley|
|2|Avenue|
|3|Boulevard|
|4|Gate|
|5|Lane|
|6|Road|
|7|Square|
|8|Street|
|9|Walk|
|10|Way|
```
