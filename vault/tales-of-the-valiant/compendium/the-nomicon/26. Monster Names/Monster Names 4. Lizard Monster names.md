# Fish Monster names
This table works for place names in areas dominated by fish creatures as well as for the personal name of a fish monster. Most of these are long names for effect rather than for repeated use. If you’re going to use one of these for a place the characters will visit often, figure out a shortened version ahead of time, because that’s what the players will use.
#### Table 26-12: Fish Place/Person Name
Only one of these has dolphin-clicks in it, but you can add them in. This table doesn’t go quite as far as Dory speaking whale in Finding Nemo, but you get the idea. Dory’s whalespeak might have names like “aai-oa-ai-o-oo-a,” which honestly would really rock for the name of an underwater city if you really did the whale voice. If you try it, I salute you!

**Instructions**: Roll for a Part 1, then on either Part 2 column.
**Sample Results**: Ulloos, Guboloon, Shuaboolbaloa, Thoshuloom.
