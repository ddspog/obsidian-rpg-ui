# Hags
Most hags are named by their locations, so if you have already generated the name of the place controlled by the hag, she is probably known as the [Name-Title for a Hag] of [Place Name for a Hag].

Any naming group can be used to generate the place name for a legendary hag, but some are better than others. Recommended tables:
- [[Brittonnian 4. Brittonnian Terrain feature names#Table 6-14 Brittonnian Sinister Terrain Names (2 words)|Table 6-14: Brittonnian Sinister Terrain Names]] (the Hag of Gluim Og)
- [[Trobadoric 2. Terrain Features#Table 23-6 Trobadoric Terrain Features Table 3|Table 23-6: Trobadoric Terrain Features Table 3]] (the Witch of Ysequo)
- [[Trobadoric 2. Terrain Features#Table 23-7 Trobadoric Terrain Features Table 4|Table 23-7: Trobadoric Terrain Features Table 4]] (the Crone of Gherlonte)
- [[Russlavik 2. Place names#Table 19-5 Russlavik Terrain Names|Table 19-5: Russlavik Terrain Names]] (the Ogress of Chelza)
#### Table 26-9: Name-Titles for a Hag
**Sample Results**: the Hag of Gluim Og, the Witch of Ysequo, the Crone of Gherlonte, the Ogress of Chelza.
