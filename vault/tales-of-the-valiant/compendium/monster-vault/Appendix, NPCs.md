# Appendix, NPCs
*Complete transcription of the "**Tales of the Valiant** Monster Vault" book by **Kobold Press**.*

This appendix contains statistics for various [[Humanoid|humanoids]]. From faithful apostles to crude thugs, these NPCs can be found across the world, breathing life into any place the PCs wander. The stat blocks are presented alphabetically and assume no lineage. To make an NPC of a specific lineage that is available to PCs, add that lineage’s traits, such as [[darkvision]], to the stat block.
# NPC Features
When an NPC’s statistics include the note “Humanoid (Any Lineage)” as the creature type, you can adjust those statistics as described in the **NPC Features** table to create an NPC of the type of [[Humanoid]] detailed in the table. In this way, you can fill a city, town, or village with a particular Humanoid, such as goblins, while still using variable statistics and differing challenges. 

To use the table, choose a set of NPC statistics, such as the mage apprentice, and reference the Humanoid column for the Humanoid you want to rework as that NPC. Then, adjust the NPC’s statistics according to the information in those columns. The Traits column lists which traits and passive features, such as [[darkvision]], from that Humanoid should be added to the NPC’s statistics, and the Features column lists which actions, bonus actions, and reactions from that Humanoid should be added to the NPC’s statistics. 

For example, a powerful spellcaster might send its goblin mage apprentice to stop PCs meddling in their plans. To create a goblin mage apprentice, use the statistics of the mage apprentice as the starting point. Give the mage apprentice [[darkvision]] out to a range of 60 feet and the Nimble Escape bonus action from the goblin’s stat block, as noted in the NPC Features table. 

**_NPC Features, Save DCs, and CR._** Adding new traits and features to a creature’s statistics can increase the creature’s [[Challenge Rating]]. When adjusting statistics by using the NPC Features table, use the higher of the two CRs between the NPC statistics you are adjusting and the lowest-CR version of the Humanoid you are using. In addition, increase any save DCs to match the save DCs in the higher-CR creature’s statistics. In the above example, the goblin mage apprentice’s Challenge Rating is 1, as the mage apprentice’s CR (1) is higher than the lowest-CR goblin (1/4).
