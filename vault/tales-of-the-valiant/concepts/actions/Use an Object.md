# Use an Object
```rpg feature.details
type: action
---
When you take the [[Use an Object]] action, you focus specifically on that interaction. Since you can normally interact with an object while doing something else (see [[Combat Encounters|Other Activity on Your Turn]]), such as drawing a sword as part of an attack, this action is usually only needed when you want to interact with more than one object on your turn. If an object is complex or requires an ability check to use, the GM might require this action even if it’s the only object you’ve handled this turn.
```
