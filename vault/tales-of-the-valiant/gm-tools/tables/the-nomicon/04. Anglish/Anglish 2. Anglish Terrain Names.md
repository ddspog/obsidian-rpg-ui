# Anglish Terrain Names
This is a general formula for naming anything from a country to a city to a forest to a lake. The first table is for general use, the sinister table is for places that need to sound threatening, and there is also an Optional Additional Ending table to add variation.

**Formula**: [Terrain Name] + "Forest," "Moor," etc. In a few cases you might put the terrain type ("Lake," "The River") before the proper name, such as Lake Moodkin instead of Moodkin Lake.

#### Anglish Terrain Names 3 (Optional Endings)
**Instructions**: Roll an optional ending for an Anglish Terrain Type on the column that corresponds to the general type of terrain. For a forest, as an example, you might have rolled "Wrath" using the first column of an earlier table. Here, you might add "grove" to the end of it, for "Wrathgrove." You can also add these results as a separate word to a result, so "Wrathcarg" could have "firth" added to it as "Wrathcarg Firth."
**Sample Results**: Borelcoed, Droffell, Moodcairn, Redbourne, Wattengrave, Baleholt, Cowlmersh, Dirgelyth, Pinchwater, Thorncopse.

- **Formula 1**: [Column 1 of Anglish Terrain Names 1] + [Anglish Terrain Names 3 (Optional Endings)]
- **Formula 2**: [Column 1 of Anglish Terrain Names 2 (Sinister)] + [Anglish Terrain Names 3 (Optional Endings)]
- **Formula 3**: [Anglish Terrain Names 1] + [Anglish Terrain Names 3 (Optional Endings)], but as a separate word.
